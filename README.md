# Party-Bingo 🎉

Mehrspieler-Party-Bingo mit Beweisfotos.

- Admin erstellt eine Runde und bekommt einen Session-Code.
- Spieler treten mit dem Code bei und definieren 16 eigene Bingo-Felder ("Nick fällt um" …).
- Admin startet; Späteinsteiger sind erlaubt.
- Während der Party: Feld antippen → Beweisfoto hochladen → Feld erledigt.
- Eine volle Reihe/Spalte/Diagonale = BINGO.
- Admin beendet das Spiel → Zusammenfassung mit allen Beweisfotos und Titeln.

Stack: Node/Express + PostgreSQL. Identität per Cookie (bleibt beim Neuladen erhalten), IP wird gespeichert.
